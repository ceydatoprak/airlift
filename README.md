# Airlift

HTML, CSS ve JavaScript ile geliştirilmiş, hava akışı fiziğine dayalı mobil oyun prototipi.

Oyuncu, hava akımını kontrol ederek farklı nesneleri havada tutmaya ve mümkün olduğunca ilerlemeye çalışır. Oyun sırasında yakıt, coin, hız ve denge gibi sistemler devreye girer.

## Özellikler

- Hava akışı tabanlı fizik mekaniği
- Mobil dokunmatik kontroller
- Yakıt sistemi
- Coin toplama ve harcama sistemi
- Farklı nesne türleri
- Ses efektleri
- Titreşim geri bildirimi
- Pause sistemi
- LocalStorage ile ilerleme kaydı
- Mobil uyumlu arayüz

## Kullanılan Teknolojiler

- HTML5
- CSS3
- JavaScript
- Canvas API
- Git / GitHub
- GitHub Pages
